# 不可取代，是一種失敗

> 我的標準化人生——把自己也開源的將近 19 年。

🎞 **投影片(reveal.js)**:<https://tan9.github.io/standardized-life/>
（演講者模式按 `S`，左邊投影片、右邊逐字稿與計時器；按 `Esc` 看總覽。）

這是我在現職單位的最後一場分享。

前面幾場，我把腦袋裡的東西交出去了——怎麼做、地雷在哪，連我怎麼跟 AI 工作都打包成了一個檔案（[beta.skill](https://github.com/tan9/beta.skill)）。這一場不一樣：我想交的不是「怎麼做」，是「為什麼我做了快 19 年還願意做」。

那些只有我懂的角落——PKI、Keycloak——前幾場已經交出去了，手續都辦完了。所以這套平台現在是真的撐得住沒有我。而「撐得住沒有我」，就是該放手的時候。一直在等系統完美到誰都不需要那天才走的人，多半不是負責，是捨不得。

一套要靠我才活得下去的系統，是我當初設計壞了；我現在敢走，正好證明這東西做對了。

- 倒數第二堂（打包得進檔案的我）：[beta.skill](https://github.com/tan9/beta.skill)
- 最後一堂（打包不進檔案的我）：就是這裡。
